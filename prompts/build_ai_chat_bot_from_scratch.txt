## 1. TECH STACK & SYSTEM ARCHITECTURE
- **Backend**: Python 3.11+, FastAPI, Uvicorn, SQLite3 (with WAL mode enabled), ChromaDB (Vector Search), BCrypt (Password Hashing), PyCryptodome/Cryptography (AES-128-CBC credential encryption), ReportLab & OpenPyXL (PDF & Excel Exports).
- **Autonomous Engine**: Python Asyncio / APScheduler background multi-agent crawlers (running every 60 minutes), BeautifulSoup4, Requests/HTTPX.
- **Frontend**: Single-Page Application (SPA) in `static/index.html` using Tailwind CSS (CDN), FontAwesome / Heroicons, vanilla JavaScript (ES6+), QR Code generator, jsPDF, and html2canvas.
- **Storage Layout**:
  - `data/nu_assistant.db` (Knowledge base, 33+ Department directories, 1000+ Officers, Notices, FAQs).
  - `data/nu_tokens.db` (Support tickets, Encrypted user credentials, RBAC User accounts, Audit logs).
  - `nu_vector_db/` (ChromaDB persistent vector store).
  - `backups/` (Portable atomic `.zip` disaster recovery snapshots).

## 4. BACKEND & RAG IMPLEMENTATION

### Module 1: `backend/services/token_service.py`
- Token generation with atomic numeric increment: `NU-YYYY-000001`.
- AES-128-CBC encryption/decryption helper for student credentials.
- Lifecycle transitions with audit logging (`CREATE` -> `ASSIGN` -> `PROCESSING` -> `SOLVE` -> `SOFT_DELETE` -> `RESTORE`).

### Module 2: `backend/services/backup_service.py`
- Create point-in-time `.zip` archives containing database snapshots and metadata manifests.
- Safe restore mechanism with automated pre-restore rollback snapshots.

### Module 3: `backend/rag_engine.py`
- Hybrid retrieval: Exact SQL officer/notice matches + ChromaDB semantic vector search.
- Preloaded instant sub-millisecond triggers (`hi`, `?????`, `?????`, `ems`, `???????`).
- System prompt enforcing English numerals for phones, official portal citations, and bilingual support (Bangla/English).

### Module 4: `crawler/` (Autonomous 60-Minute Agent)
- `departments_scraper.py`: Iterates across 33+ official departments (VC Office, Registrar, Controller of Exams, Transport, ICT Cell, Accounts, etc.), parses faculty cards, normalizes Bengali digits to English, and populates `nu_assistant.db` + ChromaDB.
- `scheduler.py`: Background cron worker running every 60 minutes during FastAPI app lifespan.

### Module 5: `backend/api/` FastAPI Routes
- `POST /api/v1/chat`: AI Assistant queries with RAG context.
- `POST /api/v1/tokens/create`: Public student support token generation.
- `GET /api/v1/tokens/status/{token_id}`: Public ticket tracking.
- `POST /api/v1/auth/login`: JWT login for Admins and Solvers.
- `GET /api/v1/admin/tokens`: RBAC-filtered token listing.
- `POST /api/v1/admin/tokens/{id}/solve` & `POST /api/v1/admin/tokens/{id}/send-back`.
- `GET /api/v1/admin/backup/list`, `POST /api/v1/admin/backup/create`, `POST /api/v1/admin/backup/restore`.
- `GET /api/v1/admin/logs/export/pdf` & `GET /api/v1/admin/logs/export/excel`.

## 5. ROLE-BASED ACCESS CONTROL (RBAC)
- **SUPER_ADMIN**: Full system control, Department Desk management, User creation/passwords, Disaster Recovery (Backup/Restore), Trash soft-delete & recovery.
- **ADMIN**: Token management, Website structure map, Autonomous Crawler engine triggers, Activity logs & PDF/Excel exports.
- **SOLVER**: Desk-restricted view. Solvers ONLY see the `Token Support Center` tab and ONLY tickets assigned to their department desk. Solvers have only 2 actions: `Solve` or `Send Back to Admin (Not Solved)`.
