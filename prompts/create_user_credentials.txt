```text

IMPORTANT:

============================================================
3. PASSWORD ENCRYPTION
============================================================

Passwords must be encrypted before being stored.

Do NOT use:

MD5
SHA1
Base64
plain text
reversible custom encryption

Use a strong authenticated encryption mechanism such as:

AES-256-GCM

or an equivalent modern authenticated encryption library.

The encryption key must come from an environment variable or secure
secret-management system.

Example:

CREDENTIAL_ENCRYPTION_KEY

Never store the encryption key in the database.

Never commit it to Git.

Never put it in frontend code.

============================================================
4. IMPORTANT SECURITY DISTINCTION
============================================================

Do NOT hash service passwords if the application needs to retrieve
the password later to log into an external service.

Password hashing is appropriate when only password verification is
required.

For external-service automation, use:

Encrypted at rest
+
Strict access control
+
Decryption only when absolutely required

The decrypted password should exist in memory only for the shortest
possible time.

Never log decrypted credentials.

============================================================

Prefer:

    ↓

    ↓
return result

The password should never be sent to the solver's browser.
```

### একটি গুরুত্বপূর্ণ পরিবর্তন

আপনার আগের Token Service architecture-এ আমি `user_service_credentials`-কে **Token table-এর ভিতরে রাখতাম না**।

বরং:

```text
USER
 │
 ├───────────────┐
 │               │
 ▼               ▼
TOKEN         CREDENTIAL
 │               │
 │               ▼
 │          EMS Credentials
 │          Form Fillup Credentials
 │          Certificate Credentials
 │
 ▼
TOKEN HISTORY
```

এতে একজন user-এর **একই EMS credential বারবার ব্যবহার করা যাবে**, কিন্তু প্রতিটি token-এর মধ্যে password copy হবে না।

আর AI-এর কাছে শুধু:

```json
{
  "service": "EMS",
  "credential_configured": true,
  "credential_status": "ACTIVE"
}
```

যাবে—**password যাবে না**। এটা আপনার system-এর security-এর জন্য খুব গুরুত্বপূর্ণ।
