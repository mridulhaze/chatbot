PART 4 — SKILL ARCHITECTURE
============================================================

A Skill is NOT a database connection.

A Skill tells the AI:

- when to use it
- what the goal is
- what steps to follow
- which MCP tools are allowed
- what information to request
- how to respond
- what privacy rules to follow
- what errors to handle

Every Skill must have a SKILL.md file.

Example:

skills/token_service/SKILL.md

The file must contain:

# Token Service Skill

## Purpose

Manage user support requests for NU-related problems.

## Trigger Conditions

Activate when:

- user selects Token Service
- user asks to create a support ticket
- user asks about a token
- user provides a Token ID
- user asks about the status of a previous problem

## Available MCP Tools

- get_services
- create_token
- get_token
- get_token_status
- get_token_history
- search_similar_solved_problems

## Workflow

1. Detect user's intent.
2. If service type is missing, show service selection.
3. Ask for problem description.
4. Search similar solved problems.
5. If similar solution exists, show anonymized solution.
6. Ask whether user wants to create a token.
7. Create token only after confirmation.
8. Return Token ID.
9. Allow user to check status later.

## Privacy

Never reveal:

- other users' identities
- phone numbers
- emails
- registration numbers
- internal notes
- private attachments
- solver private information

Only return anonymized knowledge.

## আপনার ক্ষেত্রে সবচেয়ে গুরুত্বপূর্ণ design

আমি আপনার project-এ **একটা বিশাল MCP Server** বানাতে বলব না। বরং এইভাবে রাখব:

```text
                    NU AI ASSISTANT
                           │
                    AI ORCHESTRATOR
                           │
             ┌─────────────┴─────────────┐
             │                           │
          SKILLS                       MCP
             │                           │
    ┌────────┼────────┐          ┌───────┼────────┐
    │        │        │          │       │        │
    ▼        ▼        ▼          ▼       ▼        ▼
   NU      TOKEN    EXAM       TOKEN    NU     DOCUMENT
  Skill    Skill    Skill       MCP     MCP      MCP
                                  │
                                  ▼
                           Token Database
```

এখানে **Token Skill** AI-কে workflow শেখাবে, আর **Token MCP** database-এর সাথে নিরাপদভাবে কাজ করবে।

আর সবচেয়ে গুরুত্বপূর্ণ বিষয় হলো, ভবিষ্যতে আপনি যদি **EMS-এর জন্য আলাদা database/API**, **Result database**, **Certificate system**, বা **College database** যুক্ত করেন, তখন পুরো bot rewrite করতে হবে না। শুধু নতুন MCP tools/server এবং প্রয়োজনে নতুন Skill যোগ করলেই হবে।

**Antigravity-কে prompt দেওয়ার সময় আপনার বর্তমান project folder-টিও দিন**, যাতে সে প্রথমে existing crawler, RAG, chatbot এবং database architecture inspect করে তারপর integration করে—নতুন করে একই system বানিয়ে existing কাজ নষ্ট না করে।
