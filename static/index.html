🌟 What is this platform for beginners?

This is the official AI Academic Assistant and Support Ticket Portal for National University (NU), Bangladesh (nu.ac.bd). It serves over 3 million students and teachers across Bangladesh, providing instant accurate answers, circular references, and department ticket resolution.

1 Chatting & Instant Triggers

Type questions in natural Bengali or English. Common greetings (e.g. hi, ভর্তি, রুটিন, রেজাল্ট) respond in under 1 millisecond with verified portal links.

2 Applying for Support Tokens

If you have an account or exam issue, click Token Service, select your service (EMS, Form Fillup, Rescrutiny, Certificate), and submit your details. You get a unique tracking ID (NU-2026-XXXXXX).

3 Checking Ticket Status

Click Check Token and enter your Token ID. You can see real-time updates as your ticket moves from PENDING to SOLVED with official resolution notes.

4 Mobile Camera QR Access

Click Mobile QR to display a QR code. Scan it with any smartphone camera to use the complete AI Assistant on mobile without downloading apps.

Self-Learning Vector Feedback Loop

When an authorized Department Solver marks a ticket as SOLVED and records an official resolution message, the system automatically anonymizes the student's personal information and indexes the problem-resolution pair into ChromaDB. Future students with identical problems receive the verified solution immediately from the AI!

Architecture Highlights:
• Backend: FastAPI with Non-Blocking Async Thread Offloading (asyncio.to_thread)
• AI Models: Google Gemini 3 Flash Preview & Gemini 3.1 Flash-Lite
• Vector Engine: ChromaDB with Google Generative AI Embeddings & Pseudo Fallback
• Database: Relational SQLite with WAL Mode (Write-Ahead Logging)
• Protocol: Anthropic & Antigravity Model Context Protocol (MCP) Server Suite
• Preload Engine: Sub-millisecond (18µs) memory cache for high-frequency queries

MCP Server Suite Tools

  • token_mcp: 8 tools for creating, assigning, updating, and vector-searching solved problems.
  • knowledge_mcp: Search notices, syllabus, exam guidelines, and circulars.
  • document_mcp: PDF parsing, chunking, and metadata retrieval.
  • credential_mcp: AES-128 encrypted credential status and storage.
  • enrichment_mcp: 24/7 agent telemetry, batch triggers, and JSON manifest streaming.

🤖 Multi-Agent Autonomous Loop 24/7 Active

1. ScrapedDataAnalyzerAgent: Scans crawled web pages & notices, extracts key dates/deadlines/rules, and synthesizes bilingual Q&A pairs.

2. KnowledgeEnricherAgent: Embeds synthesized Q&A into ChromaDB and updates instant preloaded caches.

3. KnowledgeProvenanceAgent: Appends updates to data/knowledge_updates.jsonl, builds RFC 8259 data/knowledge_manifest.json, and writes Markdown changelogs so peer AI agents can synchronize.

Security & Data Governance

  • 🔒 Password Hashing: PBKDF2-HMAC-SHA256 with 100,000 iterations and salt.
  • 🛡️ Credential Vault: Student service passwords encrypted using Fernet AES-128-CBC with HMAC-SHA256 authentication. Plaintext passwords are never logged or exposed.
  • 🎫 Role-Based Access: Strict permission enforcement for STUDENT, SOLVER, ADMIN, and SUPER_ADMIN.
  • 📜 Tamper-Proof Audit Trails: Every status update, login, and assignment is logged in nu_audit_log.
