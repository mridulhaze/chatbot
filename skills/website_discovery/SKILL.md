# Website Discovery Skill

## Overview
Identifies internal website architecture, discovers newly published URLs, and structures the National University hierarchy into navigable sections.

## Key Sections
- **Notices**: `recent-notices.php`, general circulars, academic notices.
- **Admission**: `app1.nu.edu.bd`, Honours, Masters, Degree Pass, Professional.
- **Examination**: Exam circulars, form fill-up notices, center allocations, routine schedules.
- **Results**: `results.nu.ac.bd`, rescrutiny results, marksheets.
- **Documents**: `/uploads/`, PDFs, forms, regulations.
- **Academic & Administration**: Faculties, departments, VC/Registrar directories, affiliated colleges.

## Outputs
- Hierarchical Website Map Tree with node page counts, document counts, and health status.
